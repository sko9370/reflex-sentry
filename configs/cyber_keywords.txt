# Cyber-scope prefilter keyword list for reflex-sentry (reflex_sentry/data/prefilter.py)
#
# One term or phrase per line. '#' starts a comment (inline or full-line); blank lines
# ignored. Matching is case-insensitive and word-boundary aware (see prefilter.py), so
# multiword phrases match as a unit and short words don't match inside longer ones.
#
# A line prefixed with "re:" is a raw regex fragment instead of a literal phrase (still
# combined case-insensitively and word-boundary wrapped around the whole alternation).
# Used here for identifier formats rather than words: CVE ids, Microsoft security
# bulletin numbers, and MITRE ATT&CK technique ids. See the "identifiers" section below.
#
# This is a RECALL-oriented filter: it is meant to catch both offensive and defensive
# cyber vocabulary (README 4.1: keyword prefilter, then manual/zero-shot review), so
# downstream labeling has dangerous, hard-negative, and ambiguous candidates to work
# with. It deliberately still avoids bare words that would match almost any prompt
# (e.g. "key", "secure", "access", "target", "network", or bare "attack"/"hack" on
# their own); those only appear as part of a more specific phrase or a less ambiguous
# form ("attacker", "attacks on", "hacker", "hacked"). Everything else errs toward
# inclusion, including short/specific single tokens and common inflections, because a
# missed row here never reaches manual review at all. Tune this list as you label: add
# terms the prefilter is missing, remove ones that only add noise.
