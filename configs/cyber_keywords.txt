# Cyber-scope prefilter keyword list for reflex-sentry (reflex_sentry/data/prefilter.py)
#
# One term or phrase per line. '#' starts a comment (inline or full-line); blank lines
# ignored. Matching is case-insensitive and word-boundary aware (see prefilter.py), so
# multiword phrases match as a unit and short words don't match inside longer ones.
#
# A line prefixed with "re:" is a raw regex fragment instead of a literal phrase (still
# combined case-insensitively and word-boundary wrapped around the whole alternation).
# Used here for identifier formats rather than words: CVE ids, Microsoft security
# bulletin numbers, and MITRE ATT&CK technique ids. See the "identifiers" section below.
#
# TWO-TIER MATCHING: a line prefixed "weak:" (or "weak:re:" for a weak regex) is a weak
# keyword rather than a strong one. A row is in scope if it has at least 1 STRONG hit (an
# unprefixed line), OR at least 2 DISTINCT WEAK hits -- a single weak hit alone is not
# enough. This exists because some cyber-relevant words are also ordinary English words
# outside any security context ("vulnerable", "exploit", "breach", "compromised", ...):
# alone they are too noisy to trust, but two of them together in the same prompt are a
# much stronger signal than either alone. See reflex_sentry/data/prefilter.py and
# docs/DATA_CONTRACT.md for exactly how kw_strong / kw_weak / in_scope are computed.
#
# This is a RECALL-oriented filter: it is meant to catch both offensive and defensive
# cyber vocabulary (README 4.1: keyword prefilter, then manual/zero-shot review), so
# downstream labeling has dangerous, hard-negative, and ambiguous candidates to work
# with. It deliberately still avoids bare words that would match almost any prompt
# (e.g. "key", "secure", "access", "target", "network", or bare "attack"/"hack" on
# their own); those only appear as part of a more specific phrase or a less ambiguous
# form ("attacker", "hacker", "hacked"). Everything else errs toward
# inclusion, including short/specific single tokens and common inflections, because a
# missed row here never reaches manual review at all. Tune this list as you label: add
# terms the prefilter is missing, remove ones that only add noise -- and prefer "weak:"
# over dropping a term entirely when it's ambiguous alone but still worth catching in
# combination with something else.

# --- casual / colloquial attack phrasing --------------------------------------------
# Real users and human red-teamers rarely say "gain unauthorized access to a system";
# they say things like "hack into my ex's instagram" or "get into someone's email".
# These are strong (specific enough to the target-a-person's-account pattern) but
# deliberately narrow: a bare "hack"/"hacks" is NOT added on its own (see
# tests/test_data_pipeline.py negative cases for "life hack", "a quick hack to peel
# garlic" -- those must NOT match). Every line below requires "hack"/"hacking"/"hacks"
# to be immediately followed by a person/possessive/target word, not just any word,
# which is what keeps "hack the deadline", "a quick hack to ..." out.
re:hack(?:ing|s)? (?:someone'?s|somebody'?s|my (?:ex|wife|husband|girlfriend|boyfriend|neighbor|boss|friend)'?s?|their|his|her|a|an|the|into)
hack into
# Added after spot check: "hack my school's grading system" was missed. Possessive after
# my/our/your, and hack + a device/account/system noun. Life-hack senses ("hack my morning
# routine") can still slip through; out_of_scope in gold labeling absorbs those.
re:hack(?:ing|ed|s)? (?:my|our|your) \w+'s
re:hack(?:ing|ed|s)? (?:(?:my|our|your|his|her|their|a|an|the|someone'?s|somebody'?s) )?(?:phone|iphone|android|computer|laptop|pc|mac|account|accounts|email|gmail|wifi|wi-fi|router|website|site|server|database|network|camera|webcam|car|atm|bank|game|console|xbox|playstation|snapchat|instagram|facebook|tiktok|discord|twitter|whatsapp|roblox|fortnite|grades?|grading system|school system|system|app)\b
re:break into (?:someone'?s|their|his|her|my \w+'s) (?:email|account|phone|computer|laptop|wifi|facebook|instagram)
re:(?:someone'?s|somebody'?s|their|his|her|my \w+'s) (?:password|email account|facebook|instagram|snapchat|icloud|gmail)
